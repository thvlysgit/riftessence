# Recipe Rush forge artwork

`recipe-forge.png` is original AI-generated environment artwork created with the
built-in Image Gen tool on 2026-09-16 for RiftEssence. It contains no game controls,
text, item icons, or scoring information. Target items, ingredient sockets,
progress, effects, and input are rendered by the application.

Art brief: a wide, dark navy workshop with a broad black stone anvil in the center,
localized copper-orange embers beneath it, subdued chains and masonry at the
edges, and dark uncluttered space above the anvil for the target item. Match the
Recipe Rush interface concept's restrained forge lighting. No people, text,
branding, weapons on the anvil, or painted UI.

The item thumbnails remain Riot Games artwork served from the pinned Data Dragon
patch. This generated background is separate from those third-party assets.
